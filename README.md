A lightweight web app that helps hiring managers and HR teams instantly generate thoughtful, role-specific interview questions. Enter a job title, and the app uses Google's Gemini AI to produce 3 tailored questions in seconds — no more spending time crafting questions from scratch.

## Features

- Role-specific question generation powered by Google Gemini AI
- Clean, minimal UI with a loading indicator during API calls
- Graceful error handling for network failures and invalid inputs
- Fully responsive layout

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) installed on your machine
- A [Google Gemini API key](https://ai.google.dev)

### Installation

```bash
bun install
```

### Environment Variables

Create a `.env` file in the root and add your Gemini API key:

```bash
VITE_GEMINI_API_KEY=your_api_key_here
```

### Running Locally

```bash
bun run dev
```
